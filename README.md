# To-Do List Web App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Press Enter to add a task
- Tasks are saved using Local Storage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Purpose

This project was created to practice frontend web development concepts including DOM manipulation, event handling, and browser Local Storage.
